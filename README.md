# Herramientas-para-el-desarrollo-de-software-y-ciberseguridad
Repositorio de recursos y herramientas esenciales para entornos de desarrollo y seguridad (DevSec). Centraliza la instalación de utilitarios, kits de compilación, lenguajes de programación y plataformas de virtualización requeridas en el programa de Técnico en Ciberseguridad.
